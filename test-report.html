✅ 缺陷 #1（已修复）：文档编辑器右键上下文菜单失效 + 未捕获异常
文件位置
frontend/src/editors/document/DocumentEditor.tsx 第 132 行
严重程度

影响用例
D19 右键菜单（菜单无法弹出）、Q2 无未捕获 Promise（抛出异常）
错误信息
TypeError: K.preventDefault is not a function（K 为压缩后的 EditorView 变量）
复现步骤
启动服务 → 切到「文档」Tab → 在编辑器内任意位置右键 → 菜单不出现，控制台报错

根因分析

ProseMirror 的 handleDOMEvents 回调签名是 (view, event)，而代码中 contextmenu 处理函数只接收了一个参数 e，导致 e 实际是 EditorView 而非事件对象：

// ❌ 当前代码（错误）
contextmenu: (e: any) => {
  e.preventDefault();          // e 是 EditorView，无 preventDefault 方法 → 抛异常
  setShowContextMenu(true);
  setContextMenuPos({ x: e.clientX, y: e.clientY });  // clientX 也为 undefined
  return false;
}

修复建议

// ✅ 修正签名：第一个参数为 view，第二个才是事件
contextmenu: (view, e) => {
  e.preventDefault();
  setShowContextMenu(true);
  setContextMenuPos({ x: e.clientX, y: e.clientY });
  return false;
}
